## ✨ Возможности

### 🧹 Очистка текста

- **Невидимые Unicode-символы** — zero-width, BOM, bidi-контролы, теги
- **«Умная» типографика** — кавычки, длинные тире, многоточия, экзотические пробелы
- **NFKC-нормализация** — свернуть совместимые символы в обычные
- **Кириллические двойники** — опционально: `а→a`, `о→o`, `е→e` (агрессивный режим)

### 🔬 Проверка «ИИ-манеры»

- **13 метрик** — разброс длины предложений, абстрактная лексика, пассивные конструкции, ИИ-штампы, плотность тире и запятых, повторы начал
- **Балл от 0 до 100** — с расшифровкой, что именно повлияло
- **Подсветка «подозрительных» предложений** — где именно сидят маркеры

### 🧠 Проверка через нейросеть (опционально)

- **Ollama + Qwen 2.5** — точность 80–85% против 65% у эвристик
- **Работает офлайн**, данные не уходят
- **Автоустановка** — приложение само предлагает скачать нейросеть

### 🔄 Перефраз

- **Замена штампов** — 70+ правил против канцелярита, работает мгновенно
- **LLM-перефраз** — переписать текст через нейросеть (экспериментально)
- **Diff-view «до/после»** — построчное сравнение с подсветкой

### 📄 Работа с файлами

- **PDF** — извлечение текста, генерация нового PDF, очистка **с сохранением вёрстки** (картинки, таблицы, шрифты, bold/italic)
- **DOCX** — чтение и очистка **с сохранением форматирования** (заголовки, таблицы, колонтитулы)
- **TXT / MD / JSON / CSV / HTML** — прямая обработка
- **Пакетная обработка** — вся папка за раз, результат в ZIP

### 🔒 Приватность

- **Всё локально** — текст не покидает ваш компьютер
- **Работает офлайн** — интернет нужен только для скачивания
- **Открытый код** — можно проверить, что ничего не утекает

## ⬇️ Установка

### macOS

1. Скачайте **`AI-Cleaner-macOS.zip`** из [Releases](https://github.com/nenenzn719-droid/ai_cleaner/releases/latest)
2. Распакуйте и перетащите `AI Cleaner.app` в **Программы**
3. **Правый клик** → **Открыть** → в диалоге снова **Открыть**
4. Откроется браузер с приложением

**Если macOS блокирует приложение:**

Откройте **Терминал** и выполните:

```bash
xattr -cr /Applications/"AI Cleaner.app"
```

Потом обычный двойной клик.

### Windows

1. Скачайте **`AI-Cleaner-Windows.zip`** из [Releases](https://github.com/nenenzn719-droid/ai_cleaner/releases/latest)
2. **Правый клик** → **Извлечь всё** (не запускайте `.exe` внутри архива!)
3. Откройте папку `AI Cleaner`
4. Двойной клик по **`AI Cleaner.exe`**
5. Если появится **SmartScreen** — **Подробнее** → **Выполнить в любом случае**

> ⚠️ SmartScreen — стандартная защита Windows. Это ложное срабатывание, программа безопасна.

## 🚀 Быстрый старт

1. **📂 Открыть файл** — выберите `.txt`, `.md`, `.pdf`, `.docx` и т.д.
2. **✨ Очистить** — удалит невидимые маркеры и типографику
3. **🔬 Проверить ИИ** — оценка «машинности» от 0 до 100
4. **🔄 Перефразировать** — заменит штампы на живые обороты
5. **💾 Сохранить** — как `.txt`, `.pdf` или `.docx`
6. **📁 Пакетно** — обработать всю папку

### Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| ⌘ O | Открыть файл |
| ⌘ S | Сохранить .txt |
| ⌘ Enter | Очистить |
| ⌘ ⇧ P | Перефразировать |
| ⌘ ⇧ K | Проверить ИИ |

## 🧠 Нейросеть через Ollama (опционально)

Приложение может использовать **локальную нейросеть** для более точной проверки и перефраза. Это **необязательно** — все базовые функции работают без неё.

### Установка прямо из приложения

1. Откройте AI Cleaner.
2. Если Ollama не установлена — появится панель **🧠 Нейросеть не установлена**.
3. Нажмите **📥 Установить Ollama** — скачается установщик.
4. Установите Ollama как обычную программу.
5. Вернитесь в приложение — через 30 секунд панель обновится.
6. Нажмите **🚀 Запустить Ollama**.
7. Нажмите **📦 Скачать модель** — начнётся загрузка ~2 ГБ.
8. Готово. Кнопки **🧠 Проверить (LLM)** и **🤖 Перефраз (LLM)** станут активными.

### Что даёт нейросеть

| Функция | Без Ollama | С Ollama |
|---------|-----------|----------|
| Проверка ИИ | 13 эвристик, ~65% | Qwen 2.5, ~85% |
| Перефраз | Замена штампов | Настоящее переписывание |
| Скорость | Мгновенно | 5–30 сек |
| Интернет | Не нужен | Только для установки |
| Приватность | Полная | Полная |

### Модели

- **`qwen2.5:3b`** — быстрая, 2 ГБ, для проверки отлично подходит.
- **`qwen2.5:7b`** — умнее, 4.5 ГБ, для перефраза лучше. Выбор в настройках (⚙️).

## 📊 Как считается «ИИ-манера»

Эвристический анализатор оценивает **13 метрик**:

| Признак | Что ищет |
|---------|----------|
| 📏 Разброс длины предложений | У ИИ они однороднее |
| 📚 Средняя длина слов | ИИ любит длинные слова |
| 🔤 Обороты-штампы | «не просто X, а Y», «важно отметить» |
| ➖ Плотность длинных тире | ИИ злоупотребляет `—` |
| 🔢 Перечисления-триады | «X, Y и Z» |
| 🌫️ Абстрактные слова | «технология», «развитие», «возможности» |
| 🔁 Повторы начал | Однотипные конструкции |
| 📐 Длина абзацев | У ИИ почти одинаковые |
| 🧊 Пассивные конструкции | «осуществляется», «было сделано» |
| 💬 Модальные глаголы | «важно», «следует», «необходимо» |
| 👤 Личные местоимения | У ИИ их мало |
| 📖 Лексическое разнообразие | Индекс Guiraud |
| 🎯 N-граммы | 16 частотных ИИ-штампов |

> 💡 **Важно:** это **не детектор авторства**, а оценка стилистики. Хороший человеческий текст может получить 30–40 баллов, если автор любит канцелярит. Числа — ориентир, не приговор.

## 🛠️ Технологии

- **Python 3.12** — логика и HTTP-сервер (стандартная библиотека)
- **pypdf** — чтение PDF
- **fpdf2** — генерация PDF
- **PyMuPDF** — работа с PDF с сохранением вёрстки
- **python-docx** — работа с Word
- **Ollama** — локальная нейросеть (опционально)
- **PyInstaller** — сборка `.app` и `.exe`

## 👨‍💻 Для разработчиков

### Локальный запуск

```bash
git clone https://github.com/nenenzn719-droid/ai_cleaner.git
cd ai_cleaner
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте `http://127.0.0.1:8765/`

### Сборка под свою ОС

**macOS:**

```bash
pyinstaller --noconfirm --clean --windowed \
  --name "AI Cleaner" --icon icon.icns \
  --add-data "index.html:." \
  --collect-all pypdf --collect-all fpdf --collect-all pymupdf --collect-all docx \
  app_launcher.py
xattr -cr "dist/AI Cleaner.app"
```

**Windows:**

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pip install pyinstaller

pyinstaller --noconfirm --clean --windowed ^
  --name "AI Cleaner" ^
  --icon icon.ico ^
  --add-data "index.html;." ^
  --collect-all pypdf ^
  --collect-all fpdf ^
  --collect-all pymupdf ^
  --collect-all docx ^
  app_launcher.py
```

Готовый `.exe` будет лежать в `dist\AI Cleaner\AI Cleaner.exe`. Упакуйте всю папку `AI Cleaner` в ZIP перед отправкой.

**Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install pyinstaller

pyinstaller --noconfirm --clean --windowed \
  --name "AI Cleaner" \
  --add-data "index.html:." \
  --collect-all pypdf --collect-all fpdf --collect-all pymupdf --collect-all docx \
  app_launcher.py
```

Готовый бинарник — в `dist/AI Cleaner/`.

### Автоматическая сборка и релизы

При каждом `git push` в `main` GitHub Actions собирает `.app` для macOS и `.exe` для Windows. Артефакты — на вкладке **Actions**.

Для публикации релиза:

```bash
git tag v2.0.1
git push origin v2.0.1
```

GitHub сам соберёт приложения и создаст страницу релиза с прикреплёнными файлами.
