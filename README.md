# AI Cleaner

**Убирает невидимые ИИ-маркеры из текста и PDF. Работает локально, без интернета.**

## Что умеет

- **Очистка текста** — удаляет невидимые Unicode-символы (zero-width, BOM, bidi), нормализует типографику, при желании заменяет кириллические двойники латиницы.
- **Проверка «ИИ-манеры»** — оценка от 0 до 100 по эвристикам: разброс длины предложений, абстрактная лексика, штампы, плотность тире, повторы начал.
- **Работа с PDF** — извлечение текста, генерация нового PDF, очистка с сохранением вёрстки (картинки, таблицы, шрифт, размер).
- **Полностью локально** — весь анализ идёт на вашем компьютере. Интернет нужен только для скачивания приложения.

## Установка

### macOS

1. Скачайте и распакуйте `AI-Cleaner-macOS.zip`.
2. Перетащите `AI Cleaner.app` в папку **Программы**.
3. Правый клик по приложению — Открыть — в диалоге снова Открыть.
4. Откроется браузер с приложением.

Если macOS блокирует — откройте Терминал и выполните:

    xattr -cr /Applications/"AI Cleaner.app"

### Windows

1. Скачайте и распакуйте `AI-Cleaner-Windows.zip`.
2. Откройте папку `AI Cleaner`.
3. Двойной клик по `AI Cleaner.exe`.
4. Если SmartScreen — Подробнее — Выполнить в любом случае.

## Как пользоваться

1. **Открыть файл** — txt, md, json, csv, html или pdf.
2. **Проверить ИИ** — оценка «машинной манеры» от 0 до 100 (ниже — человечнее).
3. **Очистить** — результат появится в правой панели.
4. **Сохранить**:
   - `.txt` — очищенный текст;
   - `.pdf` — новый PDF из очищенного текста;
   - `PDF со структурой` — оригинальный PDF с чистым текстом, сохраняя вёрстку.

Селекторы **Шрифт** и **Размер** влияют только на «PDF со структурой». Auto — берёт параметры из оригинала.

## Оценка «ИИ-манеры»

Анализатор смотрит на:

- разброс длины предложений;
- среднюю длину слов;
- характерные обороты: «не просто X, а Y», «важно отметить», «играет важную роль»;
- плотность длинных тире;
- перечисления-триады;
- долю абстрактных слов;
- повторы начал предложений;
- одинаковость длины абзацев.

Важно: это **не детектор авторства**, а оценка стилистической «машинности». Хороший человеческий текст может получить 30–40 баллов, если автор любит канцелярит.

## Технологии

- Python 3.12+ — логика и сервер
- pypdf — чтение PDF
- fpdf2 — генерация PDF
- PyMuPDF — очистка PDF с сохранением структуры
- Встроенный HTTP-сервер — интерфейс в браузере
- PyInstaller — сборка .app и .exe

## Разработка

Локальный запуск:

    git clone https://github.com/nenenzn719-droid/ai_cleaner.git
    cd ai_cleaner
    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    python app.py

Откройте http://127.0.0.1:8765/

Точка входа для сборки:

    python app_launcher.py

## Автоматическая сборка

При каждом `git push` в `main` GitHub Actions собирает `.app` для macOS и `.exe` для Windows. Артефакты — на вкладке Actions.
