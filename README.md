# AI Cleaner

Локальное приложение для очистки текста и PDF от ИИ-маркеров.

![AI Cleaner](icon.png)

## Что умеет

- 🧹 **Очистка текста** — удаляет невидимые Unicode-символы (zero-width, BOM, bidi), нормализует типографику, при желании заменяет кириллические двойники латиницы.
- 🔬 **Проверка «ИИ-манеры»** — оценка от 0 до 100 по эвристикам: разброс длины предложений, абстрактная лексика, штампы («не просто X, а Y», «важно отметить»), плотность тире, повторы начал.
- 📄 **Работа с PDF** — извлечение текста, генерация нового PDF, очистка с сохранением вёрстки (картинки, таблицы, шрифт, размер).
- 🔒 **Полностью локально** — весь анализ идёт на вашем компьютере. Интернет нужен только для скачивания приложения.

## Скачать

Готовые сборки — в разделе [**Releases**](../../releases/latest):

## Установка

### macOS

1. Скачайте и распакуйте `AI-Cleaner-macOS.zip`.
2. Перетащите `AI Cleaner.app` в папку **Программы** (Applications).
3. **Правый клик** по приложению → **Открыть** → в диалоге снова **Открыть**.
4. Откроется браузер с приложением.

Если macOS всё равно блокирует — откройте **Терминал** и выполните:

```bash
xattr -cr /Applications/"AI Cleaner.app"
